SQL Data Analytics Portfolio

SQL scripts written while preparing for Data Analyst / Data Management roles in the UAE exploratory queries, aggregations, CTEs, and window functions, each built around a realistic business question rather than a generic tutorial exercise.

About This Project
Every script here solves a specific, stated business problem against mock relational data (orders, returns, customers, and similar operational tables) — the same kind of question that comes up in live SQL technical screens. Each .sql file includes a short comment block explaining the scenario, the schema it assumes, and the approach taken.
Structure
